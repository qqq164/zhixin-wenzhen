# SENSE117连续激励与采样编排

日期：2026-10-26。固件身份为`LXB-R4-SENSE117` / `R4-P1-IRQFP-SENSE117`，`sense_protocol=1`。

## 软件改动

| 继电器 | 用途 | 规则 |
|---|---|---|
| K1～K4 | 探针接ADC、DAC、数字或GND | 保留RELAY_SET停波保护，外层确认抬针后改用途 |
| K6 | 100Ω/10kΩ量程 | 停激励后换档，重新等待DUT稳定 |
| K5、K7 | VA/VB/节点采样选择 | SENSE_SELECT只改变这两位，可保留DAC连续输出；采集和整帧传输期间拒绝切换 |

切换后进入非阻塞等待，期间拒绝启动ADC。10～60000ms为可配置范围，10ms只是调试下限，实际值须由测量头实测决定。

每帧锁定通路代际、继电器状态及record_id；悟净编排记录组号、节点、Rs档/实测值、校准ID、DDS身份与原包摘要。FDB4仍是128字节头和8192个int16采样点，未改变原传输格式。

单频流程为：配置用途/Rs并确认接触→设置激励→等待DUT稳定→VA→VB→可选节点C→VA复读。只切采样通路时不重新DAC_SET。接入现有PL结果后可按配方检查VA幅相漂移；异常和取消自动HALT，成功结束整次任务仍由外层finally停波。

HALT保持继电器位置。继电器0不代表物理断开；上电、复位及改探针用途时仍需明确抬针条件。模块没有虚构运动到位或接触反馈。
