# 测量流程与故障特征

## 模拟模式

首版针对断电无源R/RC网络，小幅正弦逐频测量。仪器内部Rs串在激励输出线上，A/B为Rs两端；注入针接激励节点，独立测量针测节点C，PCB公共地另行固定连接。单ADC分时选择测量通路。

```text
DDS → DAC → A → Rs → B → 注入针 → DUT激励节点
            │        │
            └─内部采样┘
ADC ← 高阻/选通 ← 测量针 ← DUT节点C
公共地 ───────────────── PCB GND
```

对同一频点、完成增益和相位校准后的复相量计算：

```text
I(f) = [VA(f) - VB(f)] / Rs
Zin(f) = Vport(f) / I(f)
Hnode(f) = Vnode(f) / Vreference(f)
```

这些量是复数，不用两端幅值之差替代电流所需的相量差。测量内部B与真实端口的关系时，需要考虑线缆、开关、接触和负载影响。

任务顺序为：停止输出→抬针/移动→确认到位和接触→选通与设置激励→等待稳定→采齐节点及频点→检查完整性/质量→PL计算→模型比较→存档→关闭或隔离激励后移动。

当前固件在DAC启用时拒绝所有继电器切换，包括采样VA/VB切换。整机需明确采用经硬件确认的纯采样切换策略，或停波切换后重新等待稳态；现阶段不直接删除互锁。HALT与继电器0不能被当作探针物理断开的证明。

## 特征与判断

| 类型 | 主特征 |
|---|---|
| 端口响应 | 复阻抗Z的实部、虚部 |
| 节点响应 | 各节点传递函数H的实部、虚部 |
| 异常程度 | 相对于正常参考或已知电路预测的复数偏差 |
| 质量状态 | 过量程、残差、重复散布、漂移、接触及缺测状态 |

I/Q、幅相、实虚部是同一复数的不同表达，不重复当成独立信息。不同故障可能具有相同传递函数；首版先报告异常网络及已定义单故障候选，证据不足时保留待确认状态。

## 数字模式

隔离模拟源→定义DUT供电/工作状态→两针接数字节点→同帧采集→检查静态电平或基本时序→与预期比较→存档。恒定高低电平的异常结论先定位到测点，不直接推断开路、短路或芯片损坏。
