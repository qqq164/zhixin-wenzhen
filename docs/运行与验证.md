# 运行与验证

## 离线检查

仓库根目录运行`python -B tools/run_public_checks.py`，依次执行CPU RC求解器、客户端与特征、R4整帧与相位、SENSE117编排及PL模型格式测试。入口不连接板卡，不加载SDK，也不启动输出。

CPU求解示例：

```bash
python -B software/wujing/candidates/rc_network_cpu_v1/run_rc_network.py --model software/wujing/candidates/rc_network_cpu_v1/examples/model_rc_ladder.json --output outputs/rc_prediction.json
```

先建立`outputs`目录；输出已存在时使用新文件名。

## 板上与工具链

- 7020迁移目标为XC7Z020 CLG484，历史环境为Vivado/Vitis 2025.1。源码、位流、XSA、BSP、FSBL和ELF须成套使用。
- 悟净PL驱动需要厂家匹配SDK及ABI `0x20261014`。`hardware/wujing_pl`提供自定义计算核；厂家完整工程/IP和软件依赖按本地授权环境准备。
- 模拟记录通常8192点；物理ADC/DAC时钟25MHz，低频有效采样率由抽取因子和元数据决定。
- 新板外设链路尚待联合验收，实际DUT测量还需通路、增益/相位、输入加载和接触标定。
- 网页运行方式见[网页说明](../web/circuitscout/README.md)。

## 历史测试入口

部分历史构建及原生回归脚本依赖原工程检查点、编译器位置或厂家工程。公开整理时保留源码用途说明，只将可独立运行的五组Python回归纳入统一入口。

7020原生回归也已整理所需桩和协议夹具，可单独运行：

```bash
python -B software/7020/candidates/lxb_r4_port/tests/run_tests.py --attempt local_native_01
```

需要GCC，可通过`CC`环境变量指定编译器完整路径；每次使用新的`--attempt`目录名。

本次公开整理的实际检查结果记录在[公开整理检查](../verification/公开整理检查.json)，历史板上结果另见[历史验收摘要](../verification/历史验收摘要.json)，两者范围分别记录。

## 新增117与模型格式

SENSE117六组C行为回归使用`python -B tools/test_sense117.py --attempt public_native_01`；需要GCC，使用CC可指定位置。此入口也运行27项编排模拟测试，不连接硬件。

模型接口可运行`python -B software/wujing/candidates/pl_model_export_v1/test_model_export.py`；命令行导出例子见[格式说明](../software/wujing/candidates/pl_model_export_v1/README.md)。所有新增测试与原113基线分别记录；新7020候选未加载或固化。
