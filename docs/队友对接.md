# 队友对接

| 对接方向 | 需要交接的具体成果 |
|---|---|
| DUT与模型 | 原理图、BOM及容差、注入/回流点、可接触节点；先确定一个真实R/RC网络 |
| 测量头 | 最终装配图、继电器真值表、Rs实测值、通路和量程、线缆及校准版本 |
| 机械与运动 | 控制器/协议、坐标原点与单位、回零限位、到位、接触、停止及超时反馈 |
| 数据接口 | PCB/网络/测点/频点身份、帧号、单位、固件/算法/校准版本、质量状态 |
| 故障样本 | 哪个元件如何改变、实测改值、可验证开短路、正常参考与独立验证样本 |
| 网页整合 | 一个统一任务入口，贯通运动、接触、激励、采集、计算、结果显示及存档 |

建议已有采集和算法工作继续由原负责人维护；队友优先交付DUT、测量头和运动接口，双方共同确认故障标签与验收条件。

最小目标：一块板、一个已知网络、一次到位及接触确认、完整频点记录、一次PL计算和一份可追溯结果。完成后再扩展多测点与故障分类。
