# 项目简介与方案

作品名称：**智芯问诊**。仓库名：`zhixin-wenzhen`。

本作品面向电路板调试与故障排查，设计一套融合双飞针定位、模拟扫频测量和数字信号检测的电路诊断系统。系统采用Zynq-7020与悟净LITE双板协同架构，由7020完成实时激励生成和信号采集，悟净端负责测量调度、IQ/FFT硬件计算和电路模型分析。

模拟模式首版针对断电无源电阻及RC网络。通过小幅正弦逐频激励，结合端口电压、电流及内部节点响应，提取复阻抗、传递函数等特征，并与基于原理图的节点方程预测和正常参考比较，为阻容参数异常、开路和短路等故障提供判别依据。

数字模式使用两路IO采集节点电平及变化过程，检查逻辑状态、频率、周期、脉宽、占空比和两路时序。静态数字检测必须指定DUT供电、工作状态和预期电平；不能仅凭一个高低电平直接断言某元件损坏。

最终目标扫频范围为 **1Hz～100kHz**。历史10kHz～500kHz六点属于回归配方；低频选点直连验证不等于全目标频段的模拟精度验收。

方案将结合板图测点配置、飞针定位、通路切换和数据存档，围绕“定位—激励—采集—分析—复测”组织检测，提高重复检测的一致性与可追溯性。
